## 動作確認

Node.js v25.9.0で `npm test` の15件が成功した。初期値、複数の復旧経路、偶然成功、過剰調査、scale-outの一時改善と遅延悪化、DB増強/pool制限、費用、証拠スナップショット、古い証拠、30分での未完了行動の打ち切り、終了後の操作禁止、JSON出力を対象とした。

確認中に、回復直後から安定時間を数えてしまう問題を修正した。健全化してから丸3分が必要になる。また、複数介入を挟んだ後の観測が、すべての介入を確認済みにしてしまう問題も修正した。

ブラウザで以下を操作した。

- DB観測→開発者への確認→証拠・仮説・予測・確認条件を記録→feature停止→再観測→復旧宣言→AAR。
- ECS増設完了時にP99 1.8秒、3分後にP99 4.5秒・DB接続97%・追加費用12単位となること。
- 悪化後のfeature停止→再観測→AAR→自由記述→JSON表示。表示したJSONを読み、終了理由recovered、5軸評価、7判断、入力した振り返りが含まれること。
- 導入とAARのデスクトップ表示、390px幅でのAARの折り返しと横方向のはみ出しがないこと。

ブラウザのエラーログは確認した時点で0件。アプリ内ブラウザではダウンロードイベントの完了を確認できなかったため、「保存しました」という表示を「保存を開始しました」へ修正し、JSONを表示してコピーする代替を追加・検証した。通常ブラウザでのダウンロード先への保存は未検証。
